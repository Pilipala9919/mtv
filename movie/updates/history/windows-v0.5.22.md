# Marco Movie Windows 0.5.22

本次更新为 Windows 带来 V4 柔光界面、页内搜索与同页直播，延续 0.5.21 的功能和用户数据。

发布日期：2026-11-17。应用版本：`0.5.22`（构建号 `72`）。

## 更新内容

- 顶部「首页 / 发现 / 直播 / 我的」导航。首页呈现影片与继续观看入口，发现页保留片源、仓库、分类、筛选与分页。
- 搜索改为页内宽搜索栏与横向结果卡，保留并发检索、片源选择、验证码与详情返回后的查询状态。直播采用同页播放和频道侧栏，支持跨分组搜索、线路选择与展开播放。
- 六款渐变柔光背景，可调整亮度、模糊程度与浅色 / 深色界面。支持导入本地 JPG、PNG、WebP 图片，并调整图片对齐位置；设置自动保存在本机。图片会复制到应用目录，原文件移动后仍可继续使用。
- 影片详情采用大图、简洁操作区与剧集卡片，保留收藏、下载、季集选择、正倒序、全部剧集、切换片源、网盘账号与断点续播。
- 播放器使用底部悬浮控制栏；「更多」保留原有线路、音轨、字幕、播放速度、解码策略、画面比例、跳过片头片尾、自动下一集、循环与时钟等控制。
- 「我的」集中展示收藏、观看记录与离线下载；设置中集中呈现背景、播放、内容来源、账号与同步备份，原有高级设置继续可用。
- 修复隐私空间退出时目录残留、主页验证码入口、首页与发现列表相互覆盖、换线路后错误续播，以及播放器「更多」自动隐藏的问题。补回下载批量暂停 / 继续，并改善小窗口、长片源名和高反差背景的可读性。
- 切换柔光预设或恢复默认后，已导入照片仍可重新启用；外观参数纳入备份，本地照片路径不随备份跨设备传递。

## 原有功能与数据

本次只在 Windows 上启用新界面。现有订阅、网盘账号、收藏、观看记录、下载任务、同步与隐私空间继续使用原有服务和存储格式。0.5.21 的网盘分片代理、同站备用条目解析与脚本源兼容逻辑保持沿用。

安装更新前请退出旧版程序。背景图片属于本机外观设置，不会随订阅或观看记录同步到其他设备。
