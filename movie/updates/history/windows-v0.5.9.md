# Marco Movie Windows 0.5.9

发布日期：2026-11-10。各平台独立推进版本。

## 新增与修复

- 修复资源拉取时原片源被内置采集池替换的问题。删除插件失败后自动跨源、按同名影片混入线路的行为，保留手动换源与明确片单的真实来源匹配。
- 原站目录、分类、搜索和详情保留原始影片标识与网盘文件。移除音乐、听书、体育和聚合直播插件指向无关服务的映射；未支持或失效来源明确提示。
- 修复旧详情缓存混入外站直链、App V2 请求丢失配置查询参数，以及桌面脚本服务读取错误网盘凭据存储键的问题。
- 补充 UC、百度、阿里、夸克原分享文件读取与临时播放凭据处理；扫码票据交换成真实会话后才保存登录状态，保留服务实际返回的文件和画质。
- 分享超时、切集、退出或换账号会停止旧请求；同一文件切换画质保留本机代理，修复旧账号及旧播放操作继续占用的问题。

## 验证与范围

本平台 GitHub 原生构建通过，461 项 Flutter 测试通过；共享公开内容检查、运行时回归和 7 项平台生成检查通过。测试覆盖实际本机 HTTP、Node、QuickJS、原片源归属、网盘账号同步及播放代理生命周期。

提供 Windows x64 安装版与免安装版，包内主程序版本为 `0.5.9`。

安装包版本、ZIP 完整性和 SHA-256 已核对，新旧兼容文件名对应相同字节。附带该构建提交的完整公开源码和校验文件。

本次不代表任意订阅或插件均已兼容。网盘协议自动化使用合成响应，未使用用户账号；真实账号、会员文件及 HEVC/HDR 等影片播放仍需实机验证。iOS、Android 和 Lite 不随此次桌面版本发布。
