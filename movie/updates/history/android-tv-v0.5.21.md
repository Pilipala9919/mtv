# Marco Movie Android 电视 / 盒子 0.5.21

发布日期：2026-11-12。版本代码：`79`。本次更新为电视与机顶盒端正式带来全平台互通的 **`marco-movie-sync` v2 多端网络同步**，支持大屏遥控零打字扫码直连同步与 WebDAV 自动云同步，客厅看一半切到手机、平板或电脑即可接着看。

## 全平台多端网络同步 v2（大屏扫码直连 + WebDAV 自动云同步）

- **电视扫码免输入双向同步**：电视首页欢迎页「多端同步」、观看历史页、我的收藏页、「设置 → 数据 → 多端网络同步」以及原有「手机扫码配置」弹窗均已升级支持 `/configure/<token>/sync` 双向同步协议。打开电视二维码后，同一局域网内的手机、平板或电脑无需输入密码即可一键把公开订阅源、收藏与观看进度推送并合并到电视端，解决遥控器输入长地址痛点。
- **WebDAV 自动云同步与原生 `MKCOL` 目录自建**：支持坚果云、群晖 / 威联通 NAS、Alist、Nextcloud 等标准 WebDAV 服务，采用原生套接字级 `MKCOL` 逐级创建缺失远端目录，启动后静默拉取最新记录，播放存盘、收藏增删与订阅变更后自动防抖推送。
- **可选同步公开订阅源与多订阅管理（`ConfigLibrary`）**：默认开启「同时同步我的订阅源配置」，新电视首次同步即可自动拉取并激活云端公开订阅源，亦可在片源选择器的「已添加源」中自由切换或删除多份订阅（带 `sub:` 墓碑同步防复活）；点击其他设备同步来的记录若缺少原站点，自动跳转全站聚合搜索。
- **严格隔离隐私空间与账号凭据**：进入隐私空间时彻底停用同步读写；导出订阅前自动剥离带 `isPrivate` / `private` / `hidden` / `space:"private"` 或「隐私 / 私密」分组的站点与直播源，网盘登录 Cookie / Token 与 Emby 凭据绝不上传。
