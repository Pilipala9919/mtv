## Marco Movie 0.4.22-preview (versionCode 35)

### 本次更新内容
1. **Android TV 首页选源按钮聚焦外框防裁切**：修复 FocusMotion 圆角描边内缩初始化时序并为首页头部/底栏关闭子视图裁切，使「豆豆｜片单」选源胶囊按钮聚焦时的白色外圈完整圆润不被切边。
2. **手机 / 平板 / 桌面播放器中央大尺寸播控按钮**：在播放器屏幕中央新增毛玻璃大尺寸「快退 15s / 播放暂停 / 快进 15s」主控按钮。
3. **竖屏播放一键全屏横屏切换**：在播放器独立进度条胶囊右侧与可滑动工具条中提供「全屏 / 竖屏」按钮，竖屏播放时点击自动旋转切换为横屏全屏观看，再次点击切回竖屏。
4. **播放器进度条与可滑动工具条拆分（竖屏在底部、横屏在右侧）**：将进度条胶囊与工具条拆分为独立液态毛玻璃组件；工具条完整展示所有可调节功能按钮（上集、下集、选集、线路、倍速、画面比例、全屏/竖屏、跳片头、跳片尾、连播、循环、音轨、字幕、重播），竖屏时位于底部横向滑动，横屏时自动移至右侧纵向滑动。
5. **加高 iPhone / iPad 悬浮毛玻璃 Dock 栏**：提升底部与横屏右侧悬浮 Dock 栏高度、图标尺寸与 iOS 超椭圆（Squircle）选中态胶囊比例。
6. **网盘扫码登录（我的夸父 / 我的优汐 / 我的嘟嘟 / 我的阿狸）与电视端片名、线路、选集命名对齐**：
   - 新增 🗂我的云盘┃配置 四大网盘官方扫码登录与 Token 配置弹窗；
   - 已登录网盘时自动优先聚合 4K 臻彩 / 4K 原画网盘线路（优汐智1、夸父智1、嘟嘟无限2 等）与原盘文件名选集（如 [5.20GB]E08.mkv）；
   - 将直连采集站原始代号（modum3u8、fzym3u8、dyttm3u8 等）统一转换为与电视端一致的中文线路名（魔都专线、暴风专线、电影天堂 等），并自动修复损坏的影视海报封面。
