# Marco Movie Android 电视 / 盒子 0.5.23

发布日期：2026-11-14。版本代码：`83`。本次更新重点新增订阅源各线路手动分组、单条编辑与删除，电视端搜索手机扫码输入，以及常驻 Dock 栏的电视投屏接收功能（支持 DLNA / UPnP 媒体投屏与扫码网页直投遥控），并同步升级片源防拦截回退与存储安全加固。

## 功能与同步

- 电视端悬浮 Dock 栏（右侧与顶部模式）新增「投屏」入口，内置 UPnP / DLNA 标准数字媒体渲染器（支持手机主流视频 App 在同一局域网搜索「Marco Movie TV」一键投屏并同步播放进度、快进快退与音量）及扫码网页直投遥控器（支持推送 `.m3u8` / `.mp4` 直链与可选请求头）。
- 电视端全局搜索页新增「扫码输入」按钮，生成带一次性随机令牌的局域网手机输入二维码，手机扫码即可打字或语音输入片名推送至电视立即搜索。
- 强化 WebDAV 多端同步（坚果云根目录自动追加 `MarcoMovie/` 子目录、ETag 并发冲突检测与 412 自动重试）及 `AndroidKeyStore` 敏感凭据加密保护。

## 片源与播放

- 「切换片源」升级为支持订阅源内各线路手动分组（筛选分组、新建分组、单条移动与批量分组）、手动编辑单条线路参数（名称、分组、API 地址、解析 `playUrl`、扩展 `ext`、可搜索开关及一键重置默认）与单条/批量删除及恢复已删线路；刷新订阅自动保留自定义分组与编删配置。
- 新增 `JumiTV` 及多套 `Wex` / `FTY` / `WoGG` 结构化纯数据提取适配器，优化站点镜像切换、验证码拦截提示、本机回环代理绕过、双 UA 配置拉取回退与未适配线路灰显原因展示。
- 播放进度持久化与订阅保存全面移至后台单线程序列执行器异步落盘，消除主线程磁盘同步阻塞导致的遥控焦点抽帧。
