# Marco Movie Windows 0.5.18

发布日期：2026-11-12。应用版本：`0.5.18`（构建号 `68`）。本次更新带来沉浸式无边框窗口栏、简体中文安装向导，修复升级后桌面重复生成快捷方式、多订阅线路提示缺少运行环境及部分网盘片源读取失败等反馈问题，并同步升级全端观影交互。

## 问题修复与优化

- 修复 Windows 端覆盖升级安装后桌面会重复多出一个快捷方式图标的问题。
- 修复部分网盘影视因本机代理异常、分享分页或预热条目尚未发布链接导致详情读取与播放片源失败的问题，并去除冗余的底层异常前缀提示。
- 修复连续快速滑动海报时的封面闪烁，以及看完影片返回首页未即时刷新观看历史的问题。

## 片源与播放

- 新增 32 套 `Wex` 订阅源纯数据兼容适配器，修复瓜子、独播、文才、小枫、贱片、师兄、粉猪、咸鱼、追剧、柚子等线路在 Windows 端提示「需要相应运行环境」无法使用的问题。
- 片头、片尾调节改为每部影片本机独立记录（不同步至其他影片或云端），点击播放页片头/片尾按钮优先默认设为当前播放时间并提供微调选项。
- 新增独立开关的「播放页常显时间」功能，支持隐藏控制栏后在右上角常显当前时间。

## 界面与交互

- 窗口栏升级为沉浸式无边框渐变设计（支持拖拽移动、双击最大化与全屏自动隐藏），安装向导全面切换为简体中文界面。
- 首页下滑自动加载更多海报（取消「加载更多影片」按钮），分类筛选默认收起、点击展开，并上线版本更新说明自动摘要与分类展示。
