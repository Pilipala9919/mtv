# Marco Movie macOS 0.5.16

发布日期：2026-11-14。应用版本：`0.5.16`（构建号 `66`）。本次更新新增订阅源各线路手动分组、手动编辑与单条/批量删除能力，并同步补齐更多 `Wex` / `FTY` / `WoGG` 订阅兼容、桌面交互快捷键、独立原子存储与钥匙串安全凭据加固。

## 片源与播放

- 「切换片源」全面支持对订阅源内各条线路手动创建与分配分组、批量分组、手动编辑单条线路参数（名称、分组、API 地址、解析 `playUrl`、扩展 `ext`、可搜索开关及一键重置默认）、删除单条/批量删除线路及恢复已删线路；刷新订阅后自动保留自定义分组与编删配置。
- 新增 `JumiTV` 及多套无 JIT `Wex` / `FTY` / `WoGG` 结构化纯数据提取适配器，优化源站镜像自动切换、验证码拦截识别、本机回环代理绕过及未适配片源灰显诊断原因说明。
- 播放器新增桌面快捷键（`M` 静音、`N`/`P` 切集、`[`/`]` 调速、`Cmd+W` 退出），完善流订阅释放与海报内存缓存容量治理。

## 功能与同步

- 桌面端支持鼠标拖拽滚动、横向列表滚轮滚动与悬停翻页箭头，窗口半屏贴靠自动保留侧边栏导航，并在关窗前安全完成同步推送。
- 接入 macOS 系统 Keychain 敏感凭据安全存储、独立原子文件持久化、脱敏诊断日志包导出及 WebDAV 坚果云子目录与 ETag 并发保护。
