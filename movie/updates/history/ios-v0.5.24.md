# Marco Movie iOS / iPadOS 0.5.24

发布日期：2026-11-12。应用版本：`0.5.24`（构建号 `74`），最低系统要求：iOS / iPadOS 14.0。本次更新正式上线全平台互通的 **`marco-movie-sync` v2 多端网络同步**（支持用户自配 WebDAV 自动云同步与局域网点对点免云盘直连同步），支持跨设备同步观看历史进度、我的收藏及可选的公开订阅源配置，同时严格隔离隐私空间与网盘登录凭据。

## 更新内容

1. **全平台互通的多端网络同步 v2（WebDAV 云同步 + 局域网点对点直连）**
- 支持填写坚果云、Nextcloud、Alist、群晖 NAS 等任意标准 WebDAV 服务器与应用密码：开启「自动云同步」后，启动时静默拉取最新进度，观看进度推进、收藏切换或订阅变更时自动节流推送，首次连接不存在的远端目录时自动通过 `MKCOL` 创建目录层级。
- 内置 5 分钟一次性随机会话令牌的局域网双向同步服务（`LanSyncServer`）：无需任何云服务器或账号，在同一 Wi-Fi / 局域网内打开「生成本机接收码」即可与电视、Android 手机/平板、Windows 或 macOS 客户端一键双向合并数据。
- 采用单调删除墓碑（`hist:` / `fav:` / `add:` / `sub:`）与基于时间戳的逐条合并算法，单端删除历史、取消收藏或移除订阅不会在其他设备“死而复生”，且向下兼容 v1 与 `marco-movie-backup` 载荷。

2. **可选同步公开订阅源配置与新设备一键开箱即用**
- 新增默认开启的「同时同步我的订阅源配置」开关：新安装的 iPhone / iPad 只需连接 WebDAV 或扫码局域网配对一次，即可一步拉取公开订阅仓库、观看历史进度与收藏列表并自动激活可用片源；关闭该开关时仅同步观看进度与收藏，同时完整保留云端已有的其他设备订阅列表。
- 跨端播放容错兜底：点击来自其他设备同步的历史或收藏条目时，若本机尚未导入原片源站点，将自动发起跨源同名聚合检索，无缝衔接续播。

3. **iOS 原生二级页面适配与严格的隐私 / 凭据隔离**
- 在 iOS「我的片库」顶栏新增「多端同步」快捷按钮，并在「设置 → 订阅与账号」及「设置 → 数据」中接入原生系统设置风格全屏二级页面，无底部弹窗遮挡。
- **隐私安全红线**：隐私空间（私密订阅、私密站点及其历史与收藏，含混合订阅中带隐私标记或分组的条目）、本机 `file://` 配置、四大网盘 Cookie / Token 及 Emby 凭据严格保留在本机，绝不写入云端或局域网同步载荷，也不会被远端同步覆盖。
