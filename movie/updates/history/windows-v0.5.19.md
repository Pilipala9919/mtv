# Marco Movie Windows 0.5.19

发布日期：2026-11-14。应用版本：`0.5.19`（构建号 `69`）。本次更新新增订阅源各线路手动分组、手动编辑与单条/批量删除能力，并同步升级更多 `Wex` / `FTY` / `WoGG` 订阅兼容、桌面交互快捷键、独立文件原子存储与凭据安全加固。

## 片源与播放

- 「切换片源」全面支持对订阅源内各条线路手动分组（筛选分组、新建分组、单条移动与批量分配分组）、手动编辑单条线路参数（名称、分组、API 地址、解析 `playUrl`、扩展 `ext`、可搜索开关及一键重置默认）、删除单条/批量删除线路及恢复已删线路；刷新或重导订阅后自动保留自定义分组与编删配置。
- 新增 `JumiTV` 及多套 `Wex` / `FTY` / `WoGG` 结构化纯数据提取适配器，优化站点镜像自动切换、Cloudflare / 验证码拦截提示、本机回环代理绕过及未适配片源灰显具体诊断说明。
- 播放器新增桌面快捷键（`M` 静音、`N`/`P` 切集、`[`/`]` 调速、`Ctrl+W` 退出），优化播放器流订阅释放与海报内存缓存上限。

## 功能与同步

- 桌面端支持鼠标拖拽滚动、横向列表滚轮横向滚动与悬停翻页箭头，半屏贴靠（宽度≥700）保持侧边栏导航，关窗前自动安全推送同步。
- 升级 Windows DPAPI 系统级敏感凭据安全存储、独立 JSON 原子存储架构、诊断日志一键脱敏导出及 WebDAV 坚果云子目录与 ETag 并发保护。
