# Marco Movie Windows 0.5.17

发布日期：2026-11-12。应用版本：`0.5.17`（构建号 `67`）。本次更新正式上线全平台互通的 **`marco-movie-sync` v2 多端网络同步**（支持用户自配 WebDAV 自动云同步与局域网点对点双向直连同步），打通 Windows 电脑与电视、手机、平板及 macOS 之间的观看进度、收藏列表与可选公开订阅源配置同步。

## 更新内容

- **WebDAV 自动云同步与局域网免云盘点对点同步**：支持连接坚果云、群晖 / 威联通 NAS、Alist、Nextcloud 等标准 WebDAV 服务（自动补全同步文件名并通过 `MKCOL` 创建缺失父目录），支持启动静默拉取与观看/收藏/订阅变更自动节流推送；同时内置 5 分钟令牌作用域的局域网双向同步服务（`LanSyncServer`），同一局域网内无需任何云盘账号即可与电视、手机或其他电脑扫码/粘贴地址双向合并数据。
- **可选同步公开订阅源配置与跨端换源兜底**：支持「同时同步我的订阅源配置」独立开关（默认开启），新电脑连接同步后可一次性拉取公开订阅配置、观看进度与收藏并自动启用可用片源；关闭该开关时仅同步进度与收藏且不抹除云端已有订阅。打开其他设备同步来的历史或收藏条目而本机缺少对应源站时，自动触发跨源聚合搜索。
- **桌面端快捷入口与隐私凭据本机隔离**：在桌面端「我的片库」右上角、「设置 → 订阅与账号」与「设置 → 数据」中提供液态玻璃多端同步面板；严格剔除并隔离隐私空间（私密订阅、私密站点与直播、隐私历史与收藏）、本机 `file://` 文件订阅、网盘账号 Cookie / Token 及 Emby 登录凭据。
