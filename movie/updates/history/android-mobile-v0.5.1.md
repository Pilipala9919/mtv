# Marco Movie Android 手机 / 平板 0.5.1

发布日期：2026-11-08。适用于 Android 6.0 及以上的 ARM 手机和平板。

## 重点修复

- 横屏播放控制区根据实际可用画面、刘海和系统导航区自动调整，处理进度条或按钮超出屏幕边界的问题，无需手动设置偏移。
- 缩小播放区域时调整标题和控制区布局；覆盖正反横屏、手势导航和三键导航。
- 合并重复的“继续播放”和历史入口，历史记录首位继续观看；按影片名称处理目录跳转，避免把影片编号填入搜索框。
- 修复 Android 6 字幕选项与播放设置回调的兼容问题。

Android 16 模拟器通过 122 项源检查；自适应播放布局通过 54 项检查。

## 订阅与运行兼容

- 改进 JS 模块、Python 会话与本地包读取，减少自带 Python 模块反复编译造成的启动超时。
- 新增通用 HTTP T4 请求适配；完善 TVBox 直播目录引用、插件直播目录及请求头传递。
- 更新本机 CatPaw 运行组件，支持 Android 6 所需接口，并验证手机版 64 位原生库的 16KB 内存页打包。
- 手机和电视使用独立更新通道，下载失败时保持同一设备版本重试，并校验安装包摘要、版本、设备类型和签名。

## 安装与范围

沿用原签名，可覆盖安装。**0.5.0 请先从[下载页](https://marcotv.wlj9919.top/movie/)手动选择对应设备安装一次**；升级后使用独立更新通道。手机包与电视包请勿混装。

本版先交付已验证的修复，不等待全部跨端插件移植。33 条原始插件线路的完整跨端验收、完整 CPython/原生扩展支持仍未完成；第三方源本身的失效、验证要求和设备播放能力仍可能影响使用。iPhone、macOS、Windows 和 Lite 的安装包本次不更新。
