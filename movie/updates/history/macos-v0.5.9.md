# Marco Movie macOS 0.5.9

发布日期：2026-11-10。各平台独立推进版本。

## 新增与修复

- 补齐与 iOS 用户反馈相同的百度扫码问题：保留独立二维码会话、字符串状态和长轮询进度，接收真实登录 Cookie，补全网盘会话并通过账号接口验证后才保存。重试不会重复兑换已经使用的一次性票据。
- 修复玩偶原分享标签与网盘不一致的问题。线路归属以原文件引用为准；夸克或其他网盘播放失败时不再自动跳到另一个网盘／分享而显示错误的登录提示，手动选线仍保留。
- 修复旧观看记录／收藏中的外站编号导致玩偶详情读取失败：只在同一原站核对唯一匹配条目，重新读取原目录并提示选集。无法唯一匹配时明确提示，不引入同名外站资源，也不把旧进度套到其他文件。
- 修复连续点击快进／后退 15 秒按钮误触视频背景双击、导致桌面误切全屏的问题。按钮与视频手势分层，保留背景双击全屏功能。
- 补齐百度原子目录路径与提取码、分享并发及取消、夸克部分目录提示；UC 播放代理在暂停超过五分钟后仍保留，切集、退出、换账号及最长生命周期仍会释放。

## 验证与范围

本平台 GitHub 原生 Release 构建通过，568 项 Flutter 测试通过；共享公开内容检查、运行时回归和 7 项平台生成检查通过。测试包含真实本机 HTTP、Node、QuickJS、百度账号验证成功／失败、旧编号零／唯一／多个匹配、原分享归属、鼠标与触控连续点击。

macOS 原生 Release 构建通过；包内主程序架构为 `x86_64, arm64`，版本为 `0.5.9`（构建号 `59`）。沿用本地签名分发方式，未进行 Apple 公证。

安装包版本、ZIP 完整性和 SHA-256 已核对；明确命名与旧兼容别名为相同字节。附带对应构建提交的公开源码及校验文件。旧版本发布资产保留。

网盘协议自动化使用合成响应，没有使用用户账号。真实账号、会员文件、Windows / Mac 实机与 HEVC/HDR 播放仍需验证；不代表所有第三方订阅或插件均已兼容。iOS、Android 和 Lite 不随本次桌面版本发布。
