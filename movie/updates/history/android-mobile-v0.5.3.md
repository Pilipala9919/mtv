# Marco Movie Android 手机 / 平板 0.5.3

发布日期：2026-11-08。适用于 Android 6.0 及以上的 ARM 手机和平板。

## 重点升级与修复

- **修复首页“筛选”按钮与分类胶囊重叠**：为首页横向分类滚动条增加画布级视口裁切（`clipRect`）与右侧安全间距，滑动分类胶囊时不再穿透到“筛选”按钮下方造成文字重叠。
- **修复选集详情页封面海报低清与播放按钮文字溢出**：海报加载器新增豆瓣/TMDB 大图多级回退机制（`l_ratio_poster` 遇到防盗链 403/404 时自动回退 `m_ratio_poster` 及原图并按高清分辨率解码）；移除详情页竖版海报下半部 `72×108` 低清模糊块的二次叠加涂抹；清理含换行或重复文件名的剧集标题，播放主按钮与续播提示固定单行省略，剧集缩略图启用高清解码。
- **修复多处弹窗排版错乱、内容穿透与按钮不可见**：限制遥控器焦点父级解裁切（`FocusMotion.unclipAncestors`）仅在电视端生效且不跨出滚动视口；为“选择片源”弹窗滚动区增加严格视口裁切，避免列表项上下穿透压住标题和底部操作栏；将“网盘与账号”弹窗在手机端居中自适应展示；修复“导入或更新配置”三按钮底栏在手机宽度下被挤压成空白竖条的问题，并为全部弹窗操作按钮补充清晰的深色胶囊背景与边框。
- **修复手机播放页控制栏溢出与顶栏按钮背景**：为播放页底部工具栏与滚动区启用严格圆角裁切，为顶部“返回”与“全屏横屏/退出全屏”按钮补充高对比度深色半透胶囊底色；移除播放控制层高开销截帧模糊。
- **新增导航栏字体与按钮大小自定义**：在“设置 → 界面外观与偏好”新增“导航栏字体与按钮大小”调节（`85%`–`140%`），首页分类胶囊栏、筛选按钮与底部四栏导航 Dock 自适应缩放。

## 订阅与运行兼容

- 保留 0.5.2 的海报二级磁盘缓存（`posters_v2`）、2 秒级断电续播持久化、TVBox / 影视仓加密与 XML 兼容，以及 64 位 16KB 内存页对齐的本机运行组件。

## 安装与范围

沿用原签名，可覆盖安装。**0.5.0 请先从[下载页](https://marcotv.wlj9919.top/movie/)手动选择对应设备安装一次**；升级后使用独立更新通道。手机包与电视包请勿混装。

本版先交付已验证的移动端界面、海报清晰度与播放控制修复，不等待全部跨端插件移植。33 条原始插件线路的完整跨端验收、完整 CPython/原生扩展支持仍未完成；第三方源本身的失效、验证要求和设备播放能力仍可能影响使用。iPhone、macOS、Windows 和 Lite 的安装包本次不更新。
