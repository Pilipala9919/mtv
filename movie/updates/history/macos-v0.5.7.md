# Marco Movie macOS 0.5.7

发布日期：2026-11-10。各平台独立推进版本。

## 修复

- 下载按任务分别保存，修复同名影片相互覆盖和删除的问题。
- 下载、解析接口、重定向及 HLS 子请求按来源隔离登录信息，恢复 HTTPS 证书校验。
- 保留完整片源解析配置；服务器拒绝续传时重新下载或报告失败。
- 读取实际安装版本，纠正播放策略名称，修复后台登录轮询。

## 验证与范围

桌面共享逻辑 371 项 Flutter 测试通过；本次对应原生功能另有编译和回归检查。

本次发布基于源码、自动化与安装包检查；没有把这些结果当作 iPhone、电视或其他设备的实机播放验收。真实片源、硬件解码和设备体验仍取决于实际设备与服务。
macOS 沿用现有本地签名分发方式，未新增 Apple 公证承诺。
