# Marco Movie Android TV / 盒子 0.5.18

应用版本：0.5.18（versionCode 73）。本次合并直连苹果 CMS JSON 接口导入能力，并针对电视与盒子端提升大屏遥控稳定性、播放兼容性与配对安全性。

## 更新内容

1. **支持直接导入单站 CMS JSON 接口**
- 订阅地址除多仓/单仓配置外，现支持直接粘贴单个苹果 CMS JSON `api.php/provide/vod` 接口地址并自动识别导入。
2. **电视 / 盒子播放与遥控器体验优化**
- 新增播放设置中的“隧道播放（Tunneled Playback）”开关（默认关闭），避免部分晶晨/海思/瑞芯微机顶盒开启硬件隧道后有声无画或黑屏，按需手动开启。
- 修复遥控器高频换源、快速搜索与切换详情页时的残留异步回调串台问题，自动取消已离开页面的后台请求。
3. **局域网扫码配对与数据安全加固**
- 局域网网页推送服务新增跨站请求来源校验，拦截恶意网页静默改写订阅配置；数据库缓存淘汰升级为事务原子清理。
