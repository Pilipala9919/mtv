# Marco Movie Android 手机 / 平板 0.5.23

发布日期：2026-11-14。版本代码：`84`。本次更新新增订阅源各线路手动分组、手动编辑与单条/批量删除能力，并同步补齐多套 `Wex` / `FTY` / `WoGG` 片源兼容、镜像防拦截回退、后台异步持久化与凭据安全存储加固。

## 片源与播放

- 「切换片源」全面支持对订阅源内各条线路手动创建与切换分组、批量分组、手动编辑单条线路参数（名称、分组、API 地址、解析 `playUrl`、扩展 `ext`、可搜索开关及一键恢复原始参数）、删除单条或批量删除线路以及恢复已删线路；刷新或重导同一订阅后自动保留自定义编排。
- 新增 `JumiTV` 及多套 `Wex` / `FTY` / `WoGG` 纯数据提取适配器，优化源站镜像自动切换、Cloudflare / 验证码拦截明确提示、双 UA 配置拉取回退与未适配片源灰显诊断说明。
- 播放进度记录与订阅配置保存重构为后台异步序列落盘，手机端 ZIP 扩展包导入补齐跨协议重定向与 Cookie 维护，消除主线程写入卡顿。

## 功能与同步

- 升级 WebDAV 多端同步（坚果云自动创建 `MarcoMovie/` 子目录、ETag 并发校验与 412 冲突重试），并采用 `AndroidKeyStore` AES-256-GCM 加密保护敏感配置凭据与新增「仅允许 HTTPS 插件」安全开关。
