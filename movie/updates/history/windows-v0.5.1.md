## Windows 0.5.1

此版本只更新 Windows，不要求其他平台同步升级。

1. 双击播放画面进入或退出原生真全屏，隐藏系统标题栏并覆盖任务栏区域。
2. 全屏按钮、F/F11 使用相同切换逻辑；Esc 先退出全屏，再按一次离开播放页。
3. 退出全屏或返回详情时恢复原来的窗口大小、位置或最大化状态；全屏按钮显示实际窗口状态。
4. 按当前平台独立检查更新，避免其他平台发版导致错误升级提示。
5. 保留来源返回的真实剧集信息；换源搜索保留尚未适配的线路并准确显示状态。
