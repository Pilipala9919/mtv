# Marco Movie iOS / iPadOS 0.5.26

发布日期：2026-11-14。应用版本：`0.5.26`（构建号 `76`），最低系统要求：iOS / iPadOS 14.0。本次更新新增订阅源各线路手动分组、手动编辑与单条/批量删除能力，并同步补齐更多无 JIT `Wex` / `FTY` / `WoGG` 订阅兼容、镜像防拦截回退、独立原子存储与钥匙串安全加固。

## 片源与播放

- 「切换片源」页面新增分组筛选胶囊栏与「管理分组 / 批量分组 / 批量删除 / 恢复已删」操作栏，点击线路卡片 `⋯` 或长按即可手动移动/新建分组、手动编辑单条线路参数（名称、分组、API 地址、解析 `playUrl`、扩展 `ext`、可搜索开关及一键重置默认）或删除单条线路；刷新或重导订阅后自动保留自定义编排。
- 在不依赖 JIT 与外部原生代码的前提下，补充 `JumiTV` 及多套 `Wex` / `FTY` / `WoGG` 结构化纯数据提取适配器，优化源站镜像自动切换、Cloudflare / 验证码拦截提示、本机回环代理绕过及未适配线路灰显原因展示。
- 升级播放器流订阅生命周期管理与海报缓存容量治理，减少长时间浏览与连续切集时的内存占用。

## 功能与同步

- 接入 iOS Keychain 系统钥匙串敏感凭据安全存储、PBKDF2 加盐隐私密码哈希、独立 JSON 原子存储架构、一键导出脱敏诊断日志及 WebDAV 坚果云子目录与 ETag 并发保护。
