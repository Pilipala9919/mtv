# Marco Movie Android 电视 / 盒子 0.5.3

发布日期：2026-11-08。适用于 Android 6.0 及以上的 ARM 电视和盒子。

## 重点升级与修复

- **杜比视界 / HDR 硬件解码呼出工具条零卡顿**：彻底移除播放控制层对 `GlassworkSurface`（`PixelCopy` 截帧与全树 CPU 模糊合成）的调用，改用零 GPU 离屏拷贝的硬件矢量半透图层（`chromeSurface`）；移除 `1920×1080` 全屏透明硬件层切换与字幕 `requestLayout()` 重排，解决海信 VIDAA 等电视在播放杜比视界/高码率硬解片源时按上下方向键或菜单键拉起控制栏掉帧卡顿的问题。
- **快进 / 快退仅展示纯净进度条 HUD**：播放中按左右方向键快进或快退时，隐藏顶部标题栏、底部按钮工具条及中央状态卡，仅保留进度条、时间节点与倍速快进提示；按上/下方向键或菜单键可随时展开完整工具条。
- **遥控器字幕调节交互重构**：保持上下方向键调节字幕高度（`0..180dp` 实时预览不被工具栏遮挡）、左右方向键调节字号大小，按确认键循环切换 6 种字体颜色与底衬样式（纯白、暖黄、天青、翠绿、珊瑚粉、纯白半透底）；移除电视端无法点击的触控“完成”按钮条，每次调节实时保存，按返回键或长按确认键即可完成退出。
- **分类导航栏聚焦自动切换**：首页分类标签（推荐、电影、电视剧、综艺等）支持遥控器焦点移动到位后自动切换下方片单内容，无需二次按确认键，并内置首屏内存缓存（`categoryCache`）实现切回秒显。
- **导航栏字体与按钮大小自定义及自适应排版**：在“设置 → 画面与外观”新增“导航栏字体与按钮大小”调节（`85%` / `100%` / `115%` / `130%` / `140%`），首页分类胶囊栏、片源切换胶囊与侧边/底部导航 Dock 自动按比例缩放并自适应留白与海报网格宽度。

## 订阅与运行兼容

- 保留 0.5.2 的 TVBox / 影视仓图片隐写、`2423` Hex-AES、MacCMS XML（`type=0`）与 `parses` 解析回退，以及 JS/Python/HTTP T4/CatPaw 本机运行组件；电视包保持 ARM 32 位。

## 安装与范围

沿用原签名，可覆盖安装。**0.5.0 请先从[下载页](https://marcotv.wlj9919.top/movie/)手动选择对应设备安装一次**；升级后使用独立更新通道。手机包与电视包请勿混装。

本版先交付已验证的电视端播放性能与交互升级，不等待全部跨端插件移植。33 条原始插件线路的完整跨端验收、完整 CPython/原生扩展支持仍未完成；第三方源本身的失效、验证要求和设备播放能力仍可能影响使用。iPhone、macOS、Windows 和 Lite 的安装包本次不更新。
