Marco Movie 0.3.3 Preview · 作者 Pilipala

- 内置 FFmpeg 音频、AV1 / VP9 视频软解码；修复双声道 TrueHD 与跳转问题。提供组件状态、实际播放解码信息、独立音频扩展与 AAC 音轨优先选项。
- 遥控器确认键直接暂停／继续，上下键唤出简约圆角悬浮 Dock；播放菜单保留选集、线路、倍速、画面、字幕及更多功能。
- 新增收藏页和详情收藏操作；顶部网盘按钮展开统一账号面板，移除设置中的重复账号入口。
- 20 项合成媒体/模式、19 项电视按键与页面检查通过，另有 77 项本地定向检查。测试为 Android 9 ARM32、640×360 合成样本，不代表所有设备、4K/HDR 或长期播放；音频以解码输出验证，测试时电视静音。

H.264 / H.265 继续使用设备提供的解码器，系统播放器不使用 Media3 扩展。本次不包含 IJK / MPV / MDK 内核，不承诺任意格式兼容。

APK 与源码 ZIP 均附 SHA-256；原生解码组件的完整对应源码、构建修改、许可与二进制见 https://github.com/Pilipala9919/MarcoMovie/releases/tag/decoders-1.5.1-armv7-v1 。应用遵循 GPL-3.0，各第三方组件保留自身许可。
