# Marco Movie Android 电视 / 盒子 0.6.4

发布日期：2026-11-28。应用版本 `0.6.4`（版本代码 `101`）；最低 Android 6 / API 23（32 位 `armeabi-v7a`）。本次重点优化大屏流畅度、剧集海报加载、多仓与脚本源兼容性、盘搜与弹幕体验，并上线全端 WebDAV 局域网扫码直绑与 Emby HTTP/4K 直连修复。

## 核心更新

- **大屏流畅度与海报加载优化**：
  - 优化首页与全局搜索并发调度、超时预算与大图海报切换防抖，消除快速切换片名时的海报滞后切换问题；
  - 完善高画质 / 臻彩分类剧集海报的防盗链请求头、重定向与图片格式兼容，减少海报加载失败；
  - 新增播放器 `45 分钟` 定时关闭预设、工具栏开关与右上角实时倒计时悬浮胶囊，到期自动安全停止并退出。
- **多仓线路、脚本兼容与剧集刮削加固**：
  - 修复多仓导入时部分子仓线路与自定义分组丢失问题（合并站点容量提升至 `2500`、批次上限提升至 `64`）；
  - 增强常见 JS / Python / CatVod 模块及本地代理兼容性；
  - 优化剧集刮削分词并保留年份标题线索，降低无关续作/衍生片误匹配概率。
- **盘搜与弹幕四项专项修复**：
  - **手动搜索匹配弹幕**：针对网盘加长文件名，播放菜单新增「手动搜索匹配弹幕」双栏选集弹窗并按剧集记忆绑定；
  - **盘搜网盘宽卡片展示**：搜索网盘结果以宽卡片完整显示文件名与 `4K` / `HDR` / 高码率规格标签；
  - **同词二次搜索修复**：修复搜索同一影片一次后二次触发盘搜返回空结果的问题；
  - **历史记录重开修复**：修复盘搜影片从历史记录再次进入提示「原源已失效」问题，支持自动刷新详情接口地址重试。
- **局域网扫码直绑 WebDAV & Emby 连接修复**：
  - 「我的 → 云同步 → 局域网扫码绑定」支持 `marco-bind-box-v1` 端到端加密通道，手机扫码即可将 WebDAV 配置安全推送至电视并同步触发云合并；
  - Emby 连接表单默认切换为 `HTTP（8096）` 并支持 HTTPS 切换与裸域名输入，登录支持 `/emby` 与根路径 `/` 自动回退、标准 `X-Emby-Authorization` 头与 `PlaybackInfo` 4K/多音轨 DirectPlay。
