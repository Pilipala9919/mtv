# Android 手机 / 平板 0.5.4

- **平台**：Android 手机 / 平板（`android-mobile`，ARM64 + ARMv7A，Android 6.0+）
- **版本**：`0.5.4`（`versionCode 54`）
- **发布日期**：2026-11-08
- **构建提交**：`d014a7add909237da1b2d8ee95d2a81962a10ff9`

## 本次修复与改进

1. **播放界面去蒙版与横屏显示区域对齐**：
   - 移除手机端播放控制层上下大块深色矩形遮罩（`topShade` / `bottomShade`），消除像半透明黑盒蒙版压在画面上的问题。
   - 修复从竖屏选集进入横屏全屏播放时，系统状态栏/挖孔屏历史 `WindowInsets` 导致控制层向右下错位的问题；横屏旋转完成后自动刷新安全区并将上下内边距归零。
   - 横屏播放工具栏由右侧竖列统一改为底部居中横向胶囊条，紧凑适配手机横屏高度。
2. **选集页单一换源入口**：
   - 移除选集页主播放按钮下方的重复“默认播放线路”按钮，仅保留右上角独立的换源胶囊按钮（`⇄ 线路名 ⌄`），并在右上角切换线路时自动记住首选线路。
3. **设置页与三级子菜单状态栏防重叠**：
   - 新增基于 `WindowInsets`、`DisplayCutout` 与系统资源的统一状态栏安全高度计算，修复设置页及三级子页面（软件更新、运行诊断、高级设置、首页与壁纸、播放与字幕、搜索与数据等）顶部顶到手机时间/状态栏上的问题，并为三级设置页面补充顶部圆形返回按钮与标题栏。
4. **选集页高清海报自动升级**：
   - 修复豆瓣多节点图片（`img1`/`img2`/`img9.doubanio.com`）升级 `/l_ratio_poster/` 大图时因域名被强行改写为 `img3` 导致回退低清缩略图的问题。
   - 修复选集页隐藏海报钩子尺寸被设为 `1x1` 导致解码降采样的问题，并接入官方高清竖版海报自动检索升级（豆瓣 `subject_suggest` / Rexxar 原图与 Bilibili PGC 竖版封面），加载完成后自动同步刷新选集页背景海报与剧集预览卡。
5. **选集页播放按钮文案精简**：
   - 选集页主播放按钮仅单行显示“▶ 播放 · 第 X 集”（或精简剧集名），不再在按钮内拼接冗长的资源文件名与“续播 XX:XX”；续播时间节点与线路信息统一由按钮下方小字展示。
