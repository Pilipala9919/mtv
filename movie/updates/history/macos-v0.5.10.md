# Marco Movie macOS 0.5.10

修复 Windows 0.5.10 / macOS 0.5.9 录屏反馈中的插件适配与网盘播放问题。

- 补齐实际桌面订阅携带的另一版插件，恢复对应玩偶、T4、FY、DM84 等适配，保留旧订阅版本。
- 夸克原画及转码媒体请求补齐账号会话，处理接口与媒体请求中的会话轮换。保留大文件 Range 拖动、同文件切换画质和账号切换取消。
- 为解析和起播增加等待上限，避免播放停在 00:00 时持续等待。
- 修复不同订阅的同名插件搜索去重，并在侧栏和提示中区分订阅。

macOS 原生 Release 构建通过；包内主程序架构为 `x86_64, arm64`，版本为 `0.5.10`（构建号 `60`）。沿用本地签名分发方式，未进行 Apple 公证。

实际订阅在线验证：玩偶首页 120 条，“疯狂动物城”7 条，“精武英雄”1 条。macOS 共 578 项 Flutter 检查通过，包括打包原生解码库读取合成鉴权 HEVC/MKV、播放进度、暂停和定位。

构建提交：`3c2ad0dbf3e9d4074aa35ac022169d702e4de379`。构建记录：https://github.com/Pilipala9919/MarcoMovie/actions/runs/42851117410。

合成测试不等同于用户账号的 72.8 GB 原片实播；物理 Mac 和该片完整 4K/HDR 播放仍未验收。保留原订阅与网盘账号，不替换为其他来源。第三方源的验证码、失效分享或服务故障会按实际结果提示。

安装包、免安装包、对应源码和 SHA-256 校验文件随版本提供。更新前请退出正在运行的旧程序。
