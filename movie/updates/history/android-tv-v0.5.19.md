# Marco Movie Android TV / 盒子 0.5.19

应用版本：0.5.19（versionCode 74）。本次更新重绘电视端高清矢量 Dock 图标、修复顶部 Dock 模式下左上角品牌标志对齐与固定挂载，并全面重构首页单行分类与沉浸式筛选及全引擎筛选透传能力。

## 更新内容

1. **Dock 栏高清矢量图标与顶部品牌标志对齐**
- 电视端 Dock 导航栏 6 个图标（首页、搜索、直播、收藏、网盘、设置）重绘为 `1:1` 原生屏幕物理像素坐标矢量图形并加入整数线宽像素吸附对齐，解决原有 `24x24` 画布缩放导致的边缘发虚问题；同步优化横排与竖排下当前页圆点指示器的防遮挡间距。
- 当“设置 → 首页与壁纸 → Dock 位置”设为顶部时，左上角 `MARCO MOVIE` 品牌标志改为固定挂载在顶层视口，与顶部 Dock 栏严格保持同一高度与垂直居中齐平（兼容 `85%`–`140%` 导航大小缩放），上下浏览片单时不再随页面下移或滚出屏幕。

2. **首页单行分类与沉浸式筛选重构**
- 移除电视端分类栏的“更多分类”弹窗按钮与尾部“筛选”按钮，所有类目在单行横向滑动轨道中完整展示，方向键左右移动时自动平滑居中滚动并保持流光胶囊跟随，避免向右翻分类时误触其他功能键。
- “推荐”页默认隐藏筛选面板，保持清爽浏览；切换至电影、剧集、动漫等具体分类时，分类栏下方自动展开“类型、国家 / 地区、年份”三行筛选面板（在已选中分类上按遥控器确认键也可手动展开或收起，再次点击已选筛选项可取消该条件）。
- 焦点下移进入海报墙浏览时，若已选择筛选条件则自动折叠为单行摘要条（显示已选条件并提供“修改”“重置”快捷入口），若未选择任何条件则自动完全收起让出纵向视野；进入详情页返回后完整保留当前筛选状态。

3. **全引擎分类筛选修复**
- 修复 Node / CatPaw / T4 宿主分类接口未透传 `ext` 筛选参数导致扩展爬虫筛选失效的问题，现同时解析明文 JSON 与 Base64URL 编码筛选载荷并安全转发。
- 扩展常见片源筛选字段与标题映射（兼容 `cateId`、`type`、`plot`、`yr`、剧情、分类、风格、产地等），为苹果 CMS JSON/XML 站点补齐远程参数回退、XML `<vod_class>`/`<type>` 解析及 `vod_remarks`/`vod_tag` 备注字段筛选兜底；纯本地资料筛选不足一行时自动向后补扫分页。
