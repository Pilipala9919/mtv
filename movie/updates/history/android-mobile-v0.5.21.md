# Marco Movie Android 手机 / 平板 0.5.21

发布日期：2026-11-12。版本代码：`80`。本次更新为 Android 手机与平板端正式接入全平台互通的 **`marco-movie-sync` v2 多端网络同步**，与 Android 电视、Android Lite、iOS / iPadOS、Windows 及 macOS 无缝互通观看进度、收藏列表与可选公开订阅源配置。

## 多端网络同步 v2 与移动端交互升级

- **WebDAV 自动云同步与局域网点对点双向互传**：支持坚果云、Nextcloud、Alist、NAS 等标准 WebDAV 服务（支持原生 `MKCOL` 自动创建多级目录、启动静默拉取与播放/收藏/订阅变更自动节流推送），并提供本机局域网同步二维码生成及扫码/粘贴对端地址双向合并，同一 Wi-Fi 下无需云盘即可与客厅电视、iPad 或电脑秒级同步。
- **可选公开订阅源同步与移动端「已添加源」多订阅切换**：新增默认开启的「同时同步我的公开订阅源配置」开关，新手机连接同步即可一步导入公开订阅仓库、观看历史与收藏并自动启用片源；同时为手机/平板端完整开放 `ConfigLibrary`「已添加源」管理与删除能力（设置 → 订阅与账号 → 已添加源 / 片源选择器底部入口）。点击外端同步记录若本机缺少原站点，自动回退至跨源聚合搜索。
- **全场景触控入口与严格隐私隔离**：在首次启动欢迎页、底部「片库」顶栏「多端同步」胶囊、「设置 → 订阅与账号」及「设置 → 数据」二级页面全面接入 iOS 风格深色玻璃同步面板；隐私空间内容、混合订阅中的隐私站点/直播、本机 `file://` 配置、网盘 Cookie / Token 与 Emby 凭据严格保留在本机，绝不外传。
