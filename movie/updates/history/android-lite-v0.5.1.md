# Android 4.0+ 轻量版 0.5.1

- 发布平台：Android 4.0+ 轻量版（`android-lite`，目标 API 14+ 老旧电视 / 盒子）
- 版本：`0.5.1`（`versionCode 51`）
- 发布日期：2026-11-09
- 安装包：`MarcoMovie-0.5.1-android-lite.apk`（兼容旧名：`MarcoMovie-0.5.1-lite.apk`）

## 本次新增与改进

1. **电视大屏多列网格布局与高对比度遥控器焦点体系**：
   - 新增统一顶部导航栏（`首页片源`、`当前源`、`搜索`、`直播`、`历史`、`收藏`、`配置`），支持遥控器 `MENU` 键一键回首页、`SEARCH` 键直达搜索、快速连按 `UP` 键回顶部。
   - 为所有卡片、操作按钮与横向分类/线路/选集分组胶囊统一配备琥珀金高对比度焦点边框（`#FFF5B83D`），解决旧版横向分类胶囊无遥控器焦点指示的问题。
   - 电视与横屏模式下片源列表采用 2～3 列网格，影视目录、搜索结果、观看历史与收藏采用 4～5 列海报网格；新增适配 API 14 的 `LiteImageLoader`（两阶段 `inSampleSize` 采样 + `RGB_565` 解码 + 内存 `LruCache` 与本地磁盘缓存）。

2. **电视详情页、多线路切换、剧集区间分组与跨源换源**：
   - 重构详情页顶部横幅卡片，展示封面海报、年份/地区/类型/评分徽章、主演、导演及剧情简介，提供 `▶ 立即播放 / 续播`、`♥ 加入收藏 / ★ 已收藏`、`⇅ 正序 / 倒序`、`默认播放线路` 与 `跨源换源`。
   - 新增横向播放线路标签栏与剧集区间分组标签栏（`1-40集`、`41-80集`……）配合多列选集网格，解除旧版单线路 150 集截断限制。

3. **遥控器屏幕字母/数字键盘、全站聚合搜索、观看历史与电视直播**：
   - 内置适配遥控器方向键的 `A-Z` / `0-9` / `退格` / `清空` 屏幕键盘网格与历史搜索词胶囊，支持搜索当前源与跨源并发聚合搜索。
   - 新增 `LiteStore` 持久化观看历史（跨重启记录片源、线路、集数与毫秒级播放进度）与收藏夹管理。
   - 新增电视直播页面，自动解析导入配置中的 `lives`（支持 `TXT` `#genre#` 分组、`M3U` `#EXTINF` 与 `proxy://` Base64 内联直播源）及自定义直播地址，支持直播播放时按遥控器上下方向键直接换台。

4. **电视播放器 OSD 控制栏、MacCMS XML 支持与本地回环媒体代理**：
   - 新增 4.5 秒无操作自动隐藏的播放器 OSD 顶栏与底栏；按确认键暂停/继续，按上/下方向键或菜单键聚焦底部控制栏（`暂停/播放`、`下一集`、`选集`、`换线路`、`比例：适应/铺满/16:9/4:3`、`代理：自动/始终开启/关闭`），按左右方向键支持单击 `±15s` 与长按阶梯加速快进/快退（`15s -> 25s -> 45s -> 75s -> 120s`），并支持播完自动连播下一集。
   - 扩展 `LiteCatalog` 支持 MacCMS XML（`type=0`）、`GZIP` 压缩配置、`2423` Hex-AES-128-CBC 加密配置及片源自定义 `User-Agent` / `Referer` 请求头。
   - 新增 `LiteMediaProxy` 本地 `127.0.0.1` 回环 HTTP 媒体代理：通过 Conscrypt TLS 1.2 为旧系统播放器桥接现代 HTTPS 媒体流、注入片源自定义请求头、转发 MP4 `Range` 字节范围请求（`206 Partial Content`），并自动重写 `.m3u8` HLS 播放列表中的分片与密钥相对地址。

## 验证范围

- 通过真实 API 14 `android.jar` 编译、`D8 --min-api 14` 单 DEX 校验与 V1/V2/V3 正式签名校验。
- 通过 `LiteProbe` API 14 编译/字节码校验与 `LiteJvmChecks` 53 项电视端 Lite 自动化回归测试。
- 通过 `check_public_content.py` 公开内容合规扫描。

## 已知限制

- Lite 版坚持零动态代码执行原则，`type=3` 等需要运行外部 JAR / JS / Python 爬虫的扩展源仅保留标识，不支持在 Lite 版内运行。
- 底层音视频解码仍受旧电视硬件解码器编码格式支持范围限制。
