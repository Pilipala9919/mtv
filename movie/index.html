📺 Android 电视端

专为遥控器与 10 英尺大屏打造：5–8 列 2:3 海报墙、右侧悬浮图标 Dock、内置遥控全拼/首拼搜索、左固定海报 + 右独立滚动选集、小屏返回续播、局域网扫码导入配置。

📱 Android 手机 / 平板端

完全独立的移动端触控 UI：底部固定 5 栏导航（首页、搜索、直播、我的、设置；平板横屏自动变左侧导航栏），保留系统状态栏、去除遥控白框；首页直接支持剪贴板一键粘贴与原生输入法导入（无需扫码）；支持 50 集分组触控选集与全屏横屏手势播放（双击暂停、左右滑快进、左半屏亮度、右半屏音量、长按 2 倍速）。

💻 Windows & Apple 端

提供跨平台客户端工程（覆盖 Windows x64、macOS、iPhone 与 iPad），自适应桌面侧边导航与移动端底部导航，内置硬件加速播放内核，支持与 Android 端互通备份文件。

本次更新

Marco Movie 0.4.16 Preview

- 新增 Android 手机与平板专属触控界面（MobileShell、MobileDetailScreen），与电视遥控器界面完全解耦：浏览时保留系统状态栏与底部导航栏，彻底去除触屏点击残留的遥控器白色焦点框，手机端直接进入首页不播放电视开屏动画。
- 手机端采用固定底部五栏导航（首页、搜索、直播、我的、设置），平板横屏自动切换为左侧导航栏；首页提供顶部片源胶囊切换、单行横向滑动分类条、紧凑继续观看条与 3 列触控海报网格（平板横屏 5 列）。
- 手机与平板导入配置改为首页内嵌原生输入框、剪贴板一键粘贴导入与本地 JSON 文件选择，全局网址输入直接调起手机系统输入法并支持长按粘贴，彻底移除手机端不必要的二维码扫码提示与电视虚拟字母盘。
- 手机详情页支持可折叠剧情简介、横向滑动线路胶囊、每 50 集自动分组标签、正序/倒序切换与 3 列触控选集网格；点播自动切换横屏全屏播放，支持双击暂停/继续、左右滑动快进快退、左侧上下滑调亮度、右侧上下滑调音量与长按 2 倍速快进，退出播放自动恢复竖屏。
- 新增 flutter/ 跨平台工程与云端自动构建，支持 Windows（x64 .exe）、macOS（.app）与 iOS / iPadOS（.ipa），配置与 marco-movie-backup 备份格式与 Android 端互通。
- 完成结构化诊断日志环（AppLog）、偏好范围守卫（Prefs）、按设备内存动态调整的海报缓存预算（ImageDecodePolicy）及主控制器职责拆分。

173 项纯 JVM 离线回归测试与 GitHub Actions 多平台构建全部通过。
