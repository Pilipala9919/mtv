📺 Android 电视端

专为遥控器与 10 英尺大屏打造：5–8 列 2:3 海报墙、右侧悬浮图标 Dock、内置遥控全拼/首拼搜索、左固定海报 + 右独立滚动选集、小屏返回续播、局域网扫码导入配置。

📱 Android 手机 / 平板端

完全独立的移动端触控 UI：底部固定 5 栏导航（首页、搜索、直播、我的、设置；平板横屏自动变左侧导航栏），保留系统状态栏、去除遥控白框；首页直接支持剪贴板一键粘贴与原生输入法导入（无需扫码）；支持 50 集分组触控选集与全屏横屏手势播放（双击暂停、左右滑快进、左半屏亮度、右半屏音量、长按 2 倍速）。

💻 Windows & Apple 端

提供跨平台客户端工程（覆盖 Windows x64、macOS、iPhone 与 iPad），自适应桌面侧边导航与移动端底部导航，内置硬件加速播放内核，支持与 Android 端互通备份文件。

## Marco Movie 0.4.27 Preview

### 本次更新（0.4.27 · versionCode 40）
1. **全端超清沉浸式海报与横屏 / 大屏影视详情页重构**：自动将豆瓣（`s_ratio_poster` → `l_ratio_poster`）与 B 站海报升级为 1080p 原图 URL，详情页与巨幕横幅启用原图高保真渲染（`highRes: true`）并自动将低于 36KB 的模糊采集站缩略图升级为高分辨率海报；全新设计横屏、iPad、macOS、Windows 宽屏沉浸式影院详情页与 Android 端沉浸式背景柔光。
2. **重构首页顶部「切换片源」弹窗与分组标签居中**：修复分组胶囊按钮文字垂直/水平未居中的问题，新增片源快速搜索框、带数量角标的居中液态玻璃分组胶囊栏，以及双列/三列响应式液态玻璃片源网格卡片（自动标注 `4K网盘`、`智能解析`、`直连点播`、`官方片单`）。
3. **全面扩充并去重「设置」中心**：整合为四大清晰分区（「外观与背景壁纸」「内容板块与排版布局」「播放与默认画质推荐」「云盘、订阅与数据维护」），新增 5 款 Apple 影院主题背景与自定义壁纸 URL/本地图片、海报流光氛围开关、毛玻璃浓度、网格排版密度、今日首推与继续观看板块开关、卡片副标题模式、默认画质与线路推荐（4K 网盘 / 1080P 直连 / 极速 M3U8）、默认画面比例、起播倍速、片头片尾跳过秒数及海报缓存清理，消除重复功能入口。
4. **全站搜索弹窗固定屏幕中央**：为居中模态弹窗引入 `ignoreKeyboardInsets`，调起系统软键盘输入法时弹窗固定于屏幕正中央，不再随输入法弹出而上移。
5. **修复首页底部「加载更多影片」点击后卡住无响应**：分离首次加载与分页加载状态（`_loadingMore`），修复在「推荐」标签下点击加载更多时误传无子分类的父级分类 ID 导致返回空数据的问题，并自动对分页结果去重追加。
6. **大幅提速海报封面加载与新剧搜索封面补全**：合并同名并发请求（`_inflightTitleBytes`），对慢速海外采集站图片启用 320ms 竞速回退，并发检索豆瓣 PC/移动端与国内必应高清剧照 CDN（`tse*-mm.cn.bing.net`），解决搜索新剧时封面空白或加载缓慢的问题。
