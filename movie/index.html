## Marco Movie 0.4.21 Preview

本版优化首页观感，并补齐其他平台的安装包。Android 版可在应用内“软件更新”直接覆盖升级（签名与之前的正式版一致）。

### 首页
- “切换片源”按钮改成完整的胶囊形，聚焦框跟着变圆润。
- 侧边 Dock 栏选中时的白色底改成正圆。
- 首页背景增加从上到下的柔和渐变和左右暗角；开着“海报配色柔光”或自定义壁纸时同样生效。
- 修复滚到最下面点“加载更多”后，焦点突然跳回顶部“推荐”的问题：新内容出来前焦点停在按钮上，出来后直接落到第一张新海报。

### 下载
- **Android 电视 / 手机 / 平板**：`MarcoMovie-0.4.21-preview.apk`
- **Windows 10 / 11（64 位）**：`MarcoMovie-0.4.21-windows-x64.zip`，解压后运行 `marco_movie.exe`
- **macOS、iPhone / iPad**：GitHub 苹果打包机器排队中，做好后会补传到本页（文件名 `MarcoMovie-0.4.21-macos.zip`、`MarcoMovie-0.4.21-ios-unsigned.ipa`）
- 每个文件都有同名 `.sha256` 校验文件；`MarcoMovie-0.4.21-source.zip` 为同版本源码。

说明：Windows、macOS、iOS 安装包由 GitHub Actions 云端构建并通过自动测试，尚未在每台设备上实机验证；功能以 Android 版为主，跨平台版本仍在完善。
