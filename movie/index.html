文字介绍与功能

同一版本，按遥控器、触屏和桌面操作分别适配。

Android 电视端

专为遥控器与 10 英尺大屏打造：5–8 列 2:3 海报墙、右侧悬浮图标 Dock、内置遥控全拼 / 首拼搜索、左固定海报 + 右独立滚动选集、小屏返回续播、局域网扫码导入配置。

Android 手机 / 平板端

完全独立的移动端触控 UI：支持滑动切换的玻璃 Dock、横竖屏自适应导航，保留系统状态栏、去除遥控白框；首页直接支持剪贴板一键粘贴与原生输入法导入（无需扫码）；支持 50 集分组触控选集与全屏横屏手势播放（双击暂停、左右滑快进、左半屏亮度、右半屏音量、长按 2 倍速）。

Windows 与 Apple 端

提供跨平台客户端工程（覆盖 Windows x64、macOS、iPhone 与 iPad），自适应桌面侧边导航与移动端底部导航，内置硬件加速播放内核，支持已适配来源、Emby 与本机 CatPaw，提供公开订阅备份；功能边界以本次更新说明为准。

版本特性 · 0.5.0

2026-11-07 发布 · 更新内容来自 GitHub Release 原文，改写为列表。

  1. 新增 CatPaw .js.md5 校验导入与本机运行：支持目录、搜索、详情、媒体代理、来源配置页面、多画质及分离音轨。服务包由用户提供，各端独立运行。
  2. 新增 Emby 登录、媒体库、搜索、播放协商与进度上报；完善多仓目录、JSON/XML、TXT/M3U、已适配的 JS/Python 和本地包导入。
  3. 修复删除订阅或单条线路后重新出现，处理旧配置迁移及异步请求回填；完善公开备份和私密来源隔离。
  4. 换源名称完整换行，支持排序、单条删除、默认偏好源与默认播放线路；修复分组计数背景和窄屏、大字体布局。
  5. TV 增加类型、国家地区、年份筛选，详情返回保留条件、页面、滚动与焦点；不支持服务器筛选的来源按已加载内容筛选。
  6. 设置一级菜单简化为分类，详情进入二级调整；提示避让 Dock。更新 Windows 和 Android 启动图标。
  7. 依据 Glasswork 的公开接入指南重做共用玻璃材质，原生播放器加入有界视频帧采样与减少透明效果设置。Windows 等不支持背景 shader 滤镜的环境使用模糊、高光回退。
  8. 修复 Apple CatPaw 无 JIT 启动、框架链接与打包，分离 Lite/API14 运行组件；正式 Android 安装包沿用既有签名并核验证书。修复镜像大文件链接和正式更新清单。
  9. 兼容边界
    • 原订阅仍有 33 条 Guard/Android 插件未完成跨平台移植；Android CatPaw 暂不支持 16 KB 内存页设备；Python 原生扩展、lxml 和完整 DRPY 同步宿主不属于通用已支持能力。文件导入、目录浏览、播放地址解析和实际媒体起播分别验证，不保证任意第三方来源可用。Glasswork 的多端实机性能及 iOS 14.5 巨魔启动仍待用户反馈，本版不宣称已修复该闪退。详见 跨端兼容记录。
  10. 安装包与源码
    • Android 电视版、手机/平板版、Android 4.0+ Lite、Windows 安装版/便携版、macOS Intel/Apple Silicon、iOS/iPadOS IPA，以及同版本源码。各文件附 SHA-256 校验。
