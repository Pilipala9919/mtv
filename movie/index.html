文字介绍与功能

同一版本，三端各自独立适配，不是简单拉伸。

Android 电视端

专为遥控器与 10 英尺大屏打造：5–8 列 2:3 海报墙、右侧悬浮图标 Dock、内置遥控全拼 / 首拼搜索、左固定海报 + 右独立滚动选集、小屏返回续播、局域网扫码导入配置。

Android 手机 / 平板端

完全独立的移动端触控 UI：底部固定 5 栏导航（首页、搜索、直播、我的、设置；平板横屏自动变左侧导航栏），保留系统状态栏、去除遥控白框；首页直接支持剪贴板一键粘贴与原生输入法导入（无需扫码）；支持 50 集分组触控选集与全屏横屏手势播放（双击暂停、左右滑快进、左半屏亮度、右半屏音量、长按 2 倍速）。

Windows 与 Apple 端

提供跨平台客户端工程（覆盖 Windows x64、macOS、iPhone 与 iPad），自适应桌面侧边导航与移动端底部导航，内置硬件加速播放内核，支持与 Android 端互通备份文件。

版本特性 · 0.4.36

2026-11-06 发布 · 更新内容来自 GitHub Release 原文，改写为列表。

  1. 搜索弹窗与搜索结果驻留保持（全平台）
    • 从全局搜索结果点击进入影视详情页后，按返回键退出详情页时搜索弹窗/搜索页、关键词、已检索结果列表与滚动位置完整驻留，无需重新回首页再点搜索即可直接换源选片。
  2. 跳片头 / 跳片尾支持手动拖拽精准时间节点（全平台）
    • 在播放器控制栏与设置页新增 0~300 秒（1 秒精度）手动拖拽滑块、-5s / -1s / +1s / +5s 微调按钮，以及播放器内「设为当前播放位置」一键捕获时间节点。
  3. 非直播影视进度条跳动与无总时长显示修复（全平台）
    • 修复网盘与分片代理 Content-Range / Content-Length 传递及 HLS/TS 流 maxKnownDurationMs 时长稳定化，彻底消除点播视频播放中进度条反复跳动或缺少总时长显示的问题。
  4. 播放页片名旁新增视频详情角标（全平台）
    • 在播放器顶部标题旁实时展示当前视频规格胶囊（如 4K UHD · 3840×2160 · HEVC · HDR · MKV）。
  5. 网盘 .mkv 格式视频加载与扩展片源稳定性增强
    • 为本地代理 LocalProxy 实现多段流式自动续接（Chunk-Chaining）与 .mkv 原画直连优先，修复网盘内 .mkv 视频加载不出或卡缓冲问题；为扩展源 playerContent 增加 IOException 自动重试与多线路自动回退。
  6. 方向键交互式字幕调节、弹幕自动加载与手机端无 Emoji 二级设置页重构
    • 字幕调整升级为全透明实时预览 HUD（上下键调高低位置、左右键调大小、确认键切换全透明描边/半透底样式）；手机端设置重构为无 Emoji 矢量图标二级分组菜单并原地刷新消除高刷屏重影；修复横屏右侧工具栏文字排版与顶栏长源名挤压搜索按钮问题。
  7. Windows 安装向导程序（MarcoMovie-0.4.36-windows-setup.exe）与后续版本一键更新
    • 新增 Windows 安装程序（内置 VC++ 运行库、桌面与开始菜单快捷方式、启动即显窗口）并修复 Windows 与电视端掉帧问题，支持在设置内直接检测并自动下载安装新版。
